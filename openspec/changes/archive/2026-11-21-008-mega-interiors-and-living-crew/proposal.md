# Proposal: Colossal Multi-Deck Mega-Interiors (1–420 Rooms), Fully Staffed 12-Role Living Crew & Browser Pointer-Lock Polish

## Why
Currently all 76 constructs have base interior entries of only 1–6 rooms, the Commander is clamped inside a single room without open inter-room doorways or deck turbolifts, and only a single placeholder officer mesh is rendered inside occupied interiors. To fulfill the core 1stPRTS vision (*"multiple rooms for bigger and hundreds of rooms for the biggest vehicles, fully staffed"*), we need deterministic multi-deck floorplans scaling from 1 room up to 420 rooms across 20 decks, active-deck streaming, seamless room-to-room doorway walking, turbolifts, live staffed 12-role crew agents in every room, diegetic deck blueprint minimaps, and smooth Pointer Lock / WebAudio ergonomics for the live GitHub Pages build.

## What Changes
1. **Deterministic Multi-Deck Floorplan Generator & Active-Deck Streaming (`include/rts/interior_gen.h`, `src/interior_gen.c`):** Generates 100%-connected multi-deck room graphs scaling authentically from 1 room (Starfighter) to 420 rooms across 20 decks (Orbital Shipyard Drydock) for all 76 constructs, streaming the Commander's active deck cleanly into `RtsInteriorSystem` with zero stack bloat.
2. **Seamless Room-to-Room Walking & Turbolift Transit (`src/controller.c`, `src/interior.c`, `include/rts/interior.h`):** Replaces single-room AABB clamping with multi-room connected traversal across open bulkhead doorways and adds `RTS_CONSOLE_TURBOLIFT` deck travel (`Deck 1 .. Deck N`).
3. **Living 12-Role Crew Simulation (`include/rts/crew.h`, `src/crew_sim.c`):** Deterministically staffs every active-deck room across all 12 crew roles (`officer`, `pilot`, `astrogator`, `gunner`, `shield_tech`, `comms_officer`, `engineer`, `medic`, `marine`, `hangar_crew`, `mechanic`, `quartermaster`) with role-colored Solaris trims, station work, corridor patrols, engineer damage control, and Red Alert battle-station/counter-boarding drills.
4. **Room-Specific 3D Architecture, Open Bulkheads & Diegetic Deck Blueprint Minimap (`src/retro_renderer.c`):** Renders open doorway partitions, room-specific 3D props (Holo-Globe, Reactor Tokamak, Hangar Starfighters, Turbolift Shafts, Medbay Cryo-Pods, Armory Lockers, Escape Pod Hatches), all staffed crew agents, and a live top-right Deck Blueprint Minimap.
5. **Interactive Exploration & Browser Polish (`src/platform_sdl.c`, `src/lua_vm.c`, `web/index.html`):** Adds live construct cycling (`N`), deck elevator stepping (`[`/`]` + `E` at Turbolifts), Red Alert crew drill (`F`), canvas Pointer Lock + WebAudio unlock on Chrome/desktop web, and `--capture-mega-interiors` OpenGL verification captures.
